ls|Liste les fichiers et dossiers d'ici.
ll|Liste les fichiers avec les détails (taille, date).
cd|Change de dossier. « cd .. » remonte d'un cran.
pwd|Affiche dans quel dossier tu es.
cp|Copie un fichier : cp source destination.
mv|Déplace ou renomme un fichier : mv ancien nouveau.
rm|Efface un fichier. ⚠️ Il n'y a PAS de corbeille.
mkdir|Crée un nouveau dossier.
rmdir|Efface un dossier (vide).
cat|Affiche le contenu d'un fichier texte.
nano|Ouvre un éditeur de texte simple.
touch|Crée un fichier vide (ou met à jour sa date).
echo|Affiche un texte à l'écran.
clear|Efface l'écran.
pkg|Installe/met à jour des programmes : pkg install nom.
apt|Comme pkg (sous Kali). Sur Termux, préfère « pkg ».
git|Gère des versions de code : clone, commit, push.
python|Lance le langage Python.
pip|Installe des modules Python : pip install nom.
curl|Télécharge depuis Internet ou teste une adresse.
wget|Télécharge un fichier depuis une adresse.
chmod|Change les droits d'un fichier (lecture/écriture/exécution).
ssh|Se connecte à un autre ordinateur à distance.
ping|Teste si une machine répond sur le réseau.
nmap|Scanne un réseau : appareils et ports ouverts.
ifconfig|Affiche les infos réseau (adresse IP…).
top|Montre les programmes en cours et la charge.
df|Montre l'espace disque libre.
grep|Cherche un mot dans des fichiers.
find|Cherche des fichiers par nom.
tar|Regroupe/extrait des fichiers (archives .tar).
unzip|Décompresse un fichier .zip.
kali|Entre dans Kali Linux (outils de sécurité).
lexos|Ouvre le menu LexOS.
aide|Pose une question à l'IA locale.
